🏫 Smart Campus AI
📌 Project Overview

Smart Campus AI is an AI-powered smart education assistant designed to transform the campus learning experience.
It personalizes student learning by adapting study plans based on individual performance and learning speed, while also improving campus efficiency through intelligent automation.

The system integrates learning analytics, face recognition, natural language processing, and accessibility-focused navigation to create an inclusive, data-driven academic ecosystem for modern campuses.

🚀 Key Features
1️⃣ AI-Powered Personalized Learning Assistant

Generates adaptive study plans based on student performance

Adjusts learning pace according to individual progress

Helps students focus on weak and high-priority topics

2️⃣ Smart Attendance System Using Face Recognition

Automated and contactless attendance tracking

Face recognition with anti-proxy detection

Prevents fake or proxy attendance

Reduces manual effort for faculty

3️⃣ Campus Navigation System

Designed for freshers and differently abled students

Indoor campus maps for easy navigation

Voice-based guidance for accessibility

Helps users locate classrooms, labs, offices, and facilities

4️⃣ Exam Preparation Analyzer (NLP-Based)

Analyzes previous year question papers

Identifies frequently asked and important topics

Predicts high-priority areas using NLP techniques

Enables focused and efficient exam preparation

🎯 Problem Statement

Traditional campus systems rely on generic learning methods, manual attendance, and unstructured exam preparation. These approaches fail to address individual student needs and accessibility challenges.

Smart Campus AI solves this by combining AI-driven personalization, automation, and accessibility into a single intelligent platform.

🏁 Goal

To build an inclusive, intelligent, and efficient campus ecosystem that enhances learning outcomes, reduces manual workload, and supports all students through adaptive and accessible technology.
